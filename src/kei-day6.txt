# 今すぐ僕のLINEも/Instagramも/ブロックしてください。

昨日は、僕があなたに
「禁断の初期アプローチシート」を
公開しました。

しかし、あなたは
昨日の内容を覚えていますか？

正直にお伝えしますが、
昨日のあの内容すらもう忘れているというのであれば、
あなたは本気で変わりたいというわけではないのだと
思います。

::: voice
「どうせ他の情報と同じだろう」
「どうせまたチャンスがあるだろう」
:::

きっとこれまで僕自身も
たくさん情報を発信してきて、
あなたももう情報を受け取り慣れて
きているのだと思います。

だからこそ、
「まあどうせ同じだろうな」
「まあ私には関係ない話だな」というふうに、
どこか他人事として思えているのでは
ないでしょうか。

::: box key
だから、今日で
僕のLINEも
Instagramも
ブロックしてください。
:::

もうここまで読んで、
昨日の内容を覚えていなかった女性は、
もうこれ以上何か文章を伝えたところで
本気になることはないでしょう。

きっと今こうして僕が言っていることも、
「ああ、はいはい」と
受け流すのでしょう。

だから、もうブロックしてください。

「見るな」ではなく、
もう二度と僕の発信を
見ないでください。

消えてください。

## 10年間待った末に、/子供が生まれた瞬間に縁を切られた女性の末路

僕がなんでここまで
バカみたいに本気で
あなたにこのようなことを言っているかというと、

かつて
「彼との子供を産んで、認知略奪したい」と
言っていた一人の女性が
いたからです。

!key その女性は、なんと10年間も/既婚者の彼との関係を/続けていました。

結婚適齢期も過ぎ、
子供が産めるのもそろそろ最後だからと、
40歳手前で僕にすがってきたのです。

しかし、彼女は結局、
何一つ行動を変えられませんでした。

そしてどうなったかというと――。

::: box key
なんと、彼との子供が
生まれた瞬間に、
彼に一方的に縁を切られたのです。
:::

認知もされず、
養育費の約束も反故にされ、
連絡手段もすべて断たれ、

たった一人で
生まれたばかりの赤ん坊を抱えて
放り出されました。

僕はそのような、
10年間も彼と未婚関係を持っていた女性が
そのような残酷な結果になってしまって、
すごく残念だなと思うと同時に、

ある一つの事実に気づきました。

彼女の口癖は、
いつもこうだったのです。

::: voice
「いつか彼が
変わってくれたら……」
「でも、私は平日しか
会えないから……」
:::

このように、ずっと
今ある状態、状況を
一切自分から変えようとせず、

周りからの悪い状況や
彼の都合をただ受け止めて、
自分で現実を変える気が
なくなっていたのです。

::: voice
「いつか彼が
なんとかしてくれるはず」
「今のまま優しく待っていれば、
きっと私を選んでくれるはず」
:::

そうやって「でも」「だって」と
言い訳をして
受け身のまま10年を過ごし、

いざ子供が生まれた瞬間、
保身に走った彼に
ゴミのように切り捨てられたのです。

## 僕ができる最大の愛は、/あなたに「僕をブロックさせること」です

だから、僕にとって
このような女性と同じような特徴の人は、
もう絶対に変わることはできないと
断言できます。

ここで
「でもな」「私の彼は特別だから」
「今は状況が難しいから」と言って、
今の状況を変えないのであれば、

僕と関わることは
ただの時間の無駄です。

だから、もうブロックしてください。

正直、僕ができる最大の愛は、
ここであなたに僕を
ブロックしてもらうことだと
思っています。

!key なぜか分かりますか？/そうしないと、あなたは/一生何も変わらないからです。

せめて「僕をブロックする」という
小さな変化くらいは、
自分の意志で起こしてください。

それくらい、僕は本気であなたに
「自分で決断する」ということを
してほしいのです。

確かに、ある日突然
彼が態度を変えて、
すべてを捨ててあなたを選んでくれたら、
すごく幸せでしょう。

しかし、僕が既婚男性を代表して
ハッキリとお伝えします。

::: box
既婚者が別の女性との間に子供をもうけ、
今の家庭を捨てて
そちらの女性と人生を歩むと
決めるときには、

必ず心に強烈な揺らぎが
発生します。

「本当にこれでいいのか？」
「仕事や社会的信用は
どうなる？」
「大丈夫かな？」と、
男は必ず恐怖に襲われるのです。
:::

でも、そういう
一番大切な局面の時に、
あなたが

::: voice
「いつになったら
離婚してくれるの？」
「ねえ、どうするの？」
:::

と受け身でいる限り、
男は絶対に決断できずに
怖くなって逃げ出します。

自分の人生の決断すらできない女性に、
人生を懸けた決断を迫られても、
男が背負えるわけがないのです。

だからこそ、ここで
「僕をブロックする」という行動すら
起こせないようでは、
!key 到底、既婚彼を決断させることなど/不可能です。

せめて最後に一つ、
この場で「ブロックする」という決断をして、
既婚彼を決断させられるような
強い女性になっていてほしいなと、
僕は本気で思っています。

ですから、ここまで読んで
昨日の内容を覚えていなかった女性は、
今すぐ僕のLINEもInstagramも
ブロックしてください。

今までありがとうございました。
