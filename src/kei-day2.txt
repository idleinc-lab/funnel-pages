# 「既婚彼の子供なんて/無理だよ」と言い放つ/奴らの声が、/あなたの未来を/殺している

昨日、僕が伝えた
「現実のニュース」を読んで、
胸が締め付けられた方も
多いと思います。

::: voice
「既婚者の彼との間に
子どもを望むこと」
「彼の遺伝子を残し、
彼との未来を
自分のものにしたいと
願うこと」
:::

それを心に秘めた瞬間から、
世間は冷たい目で
あなたを裁こうとします。

友達に相談すれば、
「そんなのやめときなよ、
傷つくだけだよ」と言われる。

ネットを開けば、

::: voice
「不倫の子供なんて
不幸になるに決まっている」
「どうせ愛人止まりで
捨てられる」
:::

という心無い言葉があふれている。

夜、一人でスマホの画面を
見つめながら、

::: voice
「私なんて、
やっぱり我慢しなきゃ
いけない存在なんだ……」
「どうせ私みたいな人間が、
彼との未来なんて
望んじゃいけなかったんだ……」
:::

そんな風に、
自分で自分の心を責め、
自己肯定感をすり減らして
いませんか？

今日、あなたに
一番伝えたいことがあります。

あなたが今、
これほどまでに苦しみ、
未来が見えなくなっている原因は、
あなたの願いが
間違っているからでも、

あなたの人間性が
足りないからでも
ありません。

真犯人は他にいます。

::: box key
それは、あなたの耳に
こびりつき、
心を蝕んでいる
「『どうせ無理だよ』と
決めつけてくる世間の常識と、
周りの雑音」です。
:::

## 夢を諦めさせる/「周りの声」という名の呪い

人間は、自分が本当に大切なもの
（既婚彼の子供が欲しい、
彼と生きていきたいという本心）を
抱えた時、

その思いが強ければ強いほど、
周囲の目が怖くなります。

::: voice
「そんなことしたら、
周りからなんて言われるだろう」
「常識のない女だと
思われるかもしれない」
「どうせ私なんかには、
そんな大きな幸せを
手に入れる資格はないんだ」
:::

そうやって、他人の目を恐れ、
周りの「無理だよ」という声に
怯え、
気づかないうちに
自分自身の自己肯定感を
ボロボロに破壊してしまっている。

そして、あなたを
一番苦しめているのは誰でしょうか？

――実は、彼でも、奥さんでもありません。

::: box key
「あなた自身が、
周りの雑音に屈して、
自分の可能性にフタを
してしまっていること」。
:::

これこそが、あなたを
日陰の女に閉じ込めている
最大の敵なのです。

世間の人間は勝手なことを言います。

::: voice
「既婚者の恋なんて
実るわけがない」
「子供なんて産んだら
路頭に迷う」
「おとなしく
普通の恋愛をしておきなよ」
:::

!key ふざけるな、と言いたい。

彼女たちは、
あなたの人生の責任を
取ってくれるわけでもなければ、
あなたの孤独を
埋めてくれるわけでもありません。

ただ安全な場所から、
他人の恋を石ころのように
叩いているだけです。

その「どうせ無理」という
周りの声や世間の呪いに毒されて、
あなた自身のエネルギーが
枯れ果ててしまっているからこそ、

本来持っているはずの輝きや、
未来を切り拓く力が
奪われているのです。

だから、今日から
その生き方をやめましょう。

!key 周りの声なんて、/すべて無視していい。

## 僕の母親が「無理だ」という声を/エネルギーに変えた方法

ここで、少しだけ
僕の話をさせてください。

先日お伝えした通り、
僕の母は、既婚男性との間に
僕を身ごもりました。
当時は今以上に、

世間の目は冷たく、
容赦がなかった。

まわりの友人、親族、
世間の人間――
全員が母に向かって
こう言いました。

::: voice
「頭がおかしいんじゃないか」
「そんな男の子どもを
産んだって、
絶対に認知なんて
されない」
「どうせ捨てられて、
シングルマザーで
惨めに生きるのがオチだよ」
:::

四方八方から、
「無理だ」「諦めろ」
「お前にはそんな資格はない」という
呪いの言葉が飛んできた。

普通の人なら、
そのプレッシャーに耐えきれず、
心が折れて諦めていたはずです。
だけど、母は違いました。

母は、周りから
「無理だ」「頭がおかしい」と
言われれば言われるほど、
その悔しさとエネルギーをすべて

「絶対にこの現実を
ひっくり返してやるための原動力」に
変えたのです。

世間の常識がなんと言おうと、
周りが「無理だ」と嘲笑おうと、
!key 世間の常識がなんと言おうと、/周りが「無理だ」と嘲笑おうと、/関係ない。

自分の手で、
愛する男との間に
生まれた命を守り、
未来をこじ開けてみせる。

その燃えたぎるような覚悟と
エネルギーを貫いた結果、
その男は家庭を捨てて母を選び、
再婚し、
僕という命が生まれました。

::: box key
天地が
ひっくり返るような奇跡は、
周りの「無理だよ」という声を
真に受けず、
それをエネルギーに変えた
女性の足元にしか
起きないのです。
:::

## 今日から、その「諦め」を捨てなさい

もし今、あなたが
周りの目や「どうせ無理だ」という声に
おびえて、
自分の本心を押し殺そうとしているなら。

「私なんてどうせ……」と、
自分の自己肯定感を
自分で下げているなら。

!key ――マジで、/今日からその生き方を/やめなさい。

あなたが望む未来は、
決して恥ずかしいことでも、
おかしなことでもありません。
彼の子供が欲しい、

彼と人生を共にしたいという願いは、
あなたの魂が叫んでいる
純粋な真実です。

それを「周りがこう言うから」
「世間体が悪いから」という理由で
諦める必要は、1ミリもありません。

あなたが本当に向き合うべきは、
周りの雑音ではなく、
「どうすればその未来を
自分の手で現実のものにできるのか」という
確かな道筋（戦略）だけです。

!key 世間の常識を粉砕し、/周りの「無理」という声を/ひっくり返し、
彼と自分の未来を
完全に手に入れるための
「本当の方法」は、
ちゃんと存在します。

明日の配信では、
いよいよ、僕の母が
その泥沼の現実の中で
どうやって動き、
どのようにして男の心を動かしていったのか、

その生々しいストーリーの核心を
お話しします。

::: box
周りの声に怯える毎日は、
今日で終わりにする。
その覚悟ができた方だけ、
明日の配信を
待っていてください。
:::

あなたの世界がひっくり返る瞬間は、
もうすぐ目の前です。
